`Unary` distinguishes Text identity under unary plus from conversion to Double
under unary minus. Its Binary caches expose the retained subtype: `+"1"`
stores UTF-16 `31-00`, while `-"1"` stores eight-byte Double -1. Double results
cache native status 13 for invalid numeric text and 6 for exponent overflow;
Binary unary-plus results retain the same input text even in those cases.
Large exponents, full Double precision, comma grouping, negative zero and Null
provide valid and boundary controls.

`Membership` pins native IN evaluation order. An early match bypasses a later
error, an earlier error propagates, and a Null needle bypasses its candidate
list. An unmatched value beside a Null candidate returns false. The compacted
file is an independent native output. Ordinary tests verify both specimens and
writer recomputation; a guarded DAO test repeats independent native authoring.
