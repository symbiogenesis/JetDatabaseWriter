The 38 calculated fields distinguish IN from the ordinary equality operator.
Finite numeric/Text pairs cache status 13, even when the text is a valid number.
GUIDs compare as text, including status 13 against a finite number. Date/Text
pairs compare formatted text rather than parsing dates: `1/1/2020` matches the
stored date, while `01/01/2020` and `1/1/2020 12:00:00 AM` do not. Date/number
pairs compare the native serial. Nonfinite floating/Text pairs compare native
`inf`, `-inf` and `-nan(ind)` spellings; NaN/numeric comparisons retain native
equality behavior. Earlier matches and Null needles bypass later candidates.

after writer update and insert. The separate compacted file was produced by
DAO, without any managed rewrite. Guarded fresh native controls reproduce the
mixed-type, date-text, nonfinite, Null and error-order boundaries.
